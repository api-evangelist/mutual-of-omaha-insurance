## API posture

Mutual of Omaha's Workplace Solutions unit runs a real, in-production API integration program for
group and voluntary benefits. It is NOT a public developer API. There is no developer portal, no
sign-up, no API reference, and no machine-readable contract of any kind — no OpenAPI, no AsyncAPI,
no GraphQL SDL, no Postman collection, no MCP server, no A2A agent card. The APIs are provisioned
as connections between Mutual of Omaha and a broker's or employer's benefits administration
platform, inside that platform, as part of a group insurance relationship.

An agent cannot call these APIs. An agent evaluating Mutual of Omaha as an integration target
should route through the benefits administration platform the employer already uses.

## Marketed API capabilities

- Plan Setup — pushes plan, rate and eligibility rule information directly into the benefits
  administration platform without manual intervention. Live on ADP Workforce Now, Employee
  Navigator, PlanSource.
- Evidence of Insurability (EOI) — EOI questions and automated approval/rejection decisions
  delivered inside the enrollment flow. Live on ADP Workforce Now, bswift, PlanSource.
- Enrollment — real-time election updates passed from the benefits administration platform to
  Mutual of Omaha. Announced for ADP (Q2 2026) and Workday (no date).
